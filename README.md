# PayAwaaz

Google Pay, PhonePe, Paytm या BHIM से पैसा आते ही फ़ोन हिंदी में बोलता है:
"Aman से Google Pay पर पाँच सौ रुपये आए हैं"

## android/
पूरा Android app (Java). Build: `cd android && gradle assembleDebug`.
इंस्टॉल के बाद Notification access permission देनी होती है.

## website
यही पेज एक live demo है: नाम, रकम और आवाज़ चुनकर सुनो.
